# Demonstration Scripts & Servers

This directory contains standalone and web server demonstrations across team workstreams:
- `live_demo.py`: STT (W2) pipeline live demonstration.
- `demo_reasoning.py`: Context & Reasoning (W3) demonstration.
- `demo_workflow.py`: Agentic Workflow Engine (W4) demonstration.
- `server.py`: FastAPI observability dashboard with SSE streaming.
- `server_w3.py`: Week 3 integrated audio/backend demo server.
