# Team SDE 3 API Contracts

This directory contains the cross-workstream REST API and WebSocket contract specifications:
- `agent-plan.md`: Agentic workflow plan generation and step state transitions.
- `ai-chat.md`: Real-time streaming conversational assistant contracts.
- `approvals.md`: Human-in-the-Loop approval requests, decisions, and security gates.
- `context.md`: Multimodal screen frame and context payload contracts.
- `tools-execute.md`: Consequential and read-only tool invocation specifications.
- `voice.md`: Audio streaming ingestion, VAD events, and transcription bridge contracts.
